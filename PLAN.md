# План реализации игры «1000»

## Исходное состояние

- `PROMPT.md` уже создан — это источник истины по игре.
- Git-репозитория пока нет.
- Доступны: Node.js `v26.13.0`, Git `2.42.0`, PowerShell `5.1` — этого достаточно для тестов и лаунчера.
- В проекте больше нет файлов.

---

## Как ведём работу

1. **`PROMPT.md` не меняем без согласования.** Все уточнения и отклонения фиксируем в `README.md`.
2. В этапе 0 создаём `PLAN.md` с чекбоксами по всем этапам.
3. После каждого этапа:
   - прогоняем тесты и ручные проверки;
   - отмечаем выполненные пункты в `PLAN.md`;
   - делаем коммит;
   - проверяем `git status` — рабочее дерево должно быть чистым.
4. Один этап — минимум один завершающий коммит. Внутри больших этапов можно делать несколько логических коммитов.
5. Коммиты — в стиле Conventional Commits: `feat(scope): ...`, `fix(scope): ...`, `docs: ...`, `chore: ...`, `polish: ...`.
6. Работаем в ветке `main`, история линейная. В конце — тег `v1.0.0`.
7. Если после этапа найден дефект — исправляем новым коммитом `fix: ...`, не переписываем историю через `--amend`/force push.
8. Этап считается завершённым только если:
   - код загружается без ошибок в консоли;
   - соответствующие тесты проходят;
   - ручная проверка выполнена;
   - `PLAN.md` обновлён;
   - коммит создан;
   - `git status` чистый.
